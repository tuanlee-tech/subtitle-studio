# PLAN — Việc còn lại

> Phase A (dọn dẹp repo), Phase B (gói portable — đã hủy), Phase C (clone & setup 1 lệnh)
> đều đã hoàn tất và push. Chỉ còn mục dưới đây chưa làm.

## Chưa làm

- [ ] **Verify `setup.cmd` trên Windows thật** — không có máy Windows ở đây.
      Khi nào có máy: `git clone` → double-click `setup.cmd` → `npm run dev`
      → upload → transcribe → render. Ghi nhận lỗi (nếu có) để sửa.
